# Alex Styles Portfolio

A responsive portfolio website for Alex Styles, a stylist and visual designer. Built with HTML and CSS and deployed on GitHub Pages.

**Live site:** https://YOUR-USERNAME.github.io/alex-styles-portfolio/

## Features
- Responsive layout (desktop, tablet, mobile) using CSS Grid, Flexbox and media queries
- Hover effects on navigation, buttons and project cards
- Modal windows for project details
- Tooltips on skill chips
- Keyboard focus styles and reduced-motion support
